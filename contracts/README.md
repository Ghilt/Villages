# Contracts

The wire format between the gateway and the browser, as checked-in JSON fixtures.

`fixtures/` holds one file per message type, plus vectors for the maths both sides must agree on, such as the mapping
from a location to a cell. The Kotlin `protocol` module and the TypeScript `protocol` package each have a test that
parses every fixture, round-trips it, and compares. Neither side owns the format: the fixtures do.

Add a fixture in the same change as the message type; both sides' tests fail without it.

The frames, under `fixtures/frames/client` and `fixtures/frames/server`: one frame per file, exactly as it crosses the
wire, nothing else in the file. Every frame has a `type` field naming it. Times are the server's clock in
milliseconds since the epoch, as numbers. Optional fields are left out when absent rather than written as null.
Identifiers are strings. Heraldry is spelled the way the browser shows it: `or`, `perPale`, `stag`.

`fixtures/cells.json` holds the vectors for the arithmetic from a location to a cell, generated by an implementation
independent of both sides. `fixtures/reach.json` does the same for whether a place lies within a vision point's reach,
which is what the gateway holds back by and what the page draws the fog clear inside, and `fixtures/coverage.json`
for several points together with the surface tension between them, generated by trying ball centres by brute force.
