# Villages' additions to loop:continue-for-some-time

What is true of Villages only. The shared skill's steps stand; this adds to them.

## Before starting

Write the run into this session's `.sessions/` note as well as the status file: the run picked, its steps, its stops, its
time frame and the start time (`date`). That note is where Adam looks on coming back early.

## Decisions that are Adam's, so the run stops

A matter of taste, a number Adam picks, anything in the master, a design question about a mechanic that the documents do not
answer, a button that could be a mark or words.

## Never, in a run

Bring anything to main, push, tag, rewrite history, edit the master, or stop a server that belongs to another tree.

## Commits

One per step, by the rules in `CLAUDE.md`: Conventional Commits with its scopes and the `Co-Authored-By` trailer, never red.
